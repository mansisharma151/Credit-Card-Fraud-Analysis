# Credit Card Fraud Analysis

## Project Overview
This project analyzes credit card transactions to identify fraud patterns and understand the differences between fraudulent and genuine transactions.

## Objectives
- Analyze transaction data using Python.
- Compare fraudulent and genuine transactions.
- Explore transaction amount patterns.
- Analyze fraud rates across time intervals.
- Build an interactive dashboard using Power BI.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Power BI
- Jupyter/VS Code

## Project Files
- `analysis.py` — Python analysis script.
- `creditcard.csv` — Original transaction dataset.
- `creditcard_analysis.csv` — Processed dataset.
- `average_transaction_amount.png` — Transaction amount chart.
- `fraud_rate_by_time.png` — Fraud rate chart.
- `transaction_counts.png` — Transaction count chart.
- Power BI dashboard — Interactive data visualization.

## Key Findings
- The dataset contains both fraudulent and genuine transactions.
- Fraudulent transactions are rare compared with genuine transactions.
- Transaction amount patterns and time intervals can be explored to understand fraud behavior.

## Disclaimer
This project is for educational and analytical purposes. It does not provide a production-ready fraud detection system.
